# text_by_area — dialog records linked to in-game locations

Generated by `tools/moneo/build_text_by_area.py`. Combines:

- `tools/moneo/corpus.ko.2024.json` — every Korean dialog string the
  scanner finds in the 2024-patched LeafGreen ROM, decoded against
  `rom_swap/codepoint_map.json` (currently 539 verified anchors).
- `tools/moneo/map_text_index.json` — per-map text references resolved
  by the FRLG bytecode walker (`walk_scripts_v2.py`).
- `tools/moneo/mapsec_dialog.json` — corpus records grouped by FRLG
  mapsec id.
- `tools/moneo/mapsec_areas.json` — mapsec id → canonical area name +
  confidence (high / low / frlg-canonical).

## Layout

```
text_by_area/
  pallet_town/
    0x58__MAPSEC_PALLET_TOWN.md     # high-confidence Pallet Town dialog
    0xAE__check_..._chase_line.md   # low-confidence (verify-needed)
    ...
  pewter_city/
    0x5A__MAPSEC_PEWTER_CITY.md
    ...
  unattributed.md                   # records not reached by map walker
                                    # (trainer rosters, name tables,
                                    #  Pokedex/item/system strings)
  index.json                        # programmatic index
```

Per-mapsec markdown files include the FRLG canonical name and a
**confidence** label per the source mapsec. Records inside each file
are sorted by ROM offset, which roughly corresponds to story order.

## Reading the text

Two kinds of placeholder appear in decoded strings:

- `·` — a byte sequence that decodes to a non-hangul slot (a control
  code, ASCII punctuation, or a name/buffer placeholder like
  `{var:01}`). The decoder routes these to a single-character marker
  rather than dropping them, so length and structure are preserved.
- `[XXXX]` — a hangul-range codepoint we don't yet have a label for.
  The byte data is in ROM and the atlas-1 glyph can be rendered
  directly via `tools/moneo/rom_swap/render_jamo_atlas.py` using the
  storage→internal translator from `FONT_HUNT.md` (Update 2026-05-10
  *storage→atlas codepoint translator*).

For example, in `pallet_town/0x58__MAPSEC_PALLET_TOWN.md`:

```
오박사·잠[37AF]·
····기다리거라·
```

reads roughly as *"Professor Oak: just a [moment]… wait!"*; the
unmapped codepoint `0x37AF` is some syllable in the 자/잠/잘 area.

## Coverage at the time of generation

- 1,281 distinct dialog records (out of 6,403 total) reached via
  static map-script walking and linked to one or more areas.
- 5,122 records left in `unattributed.md` — these are real Korean
  text but the static walker can't pin them to a single map (trainer
  rosters, item/Pokedex/move/ability names, system strings).
- Per-codepoint label coverage at the byte level is ~80% for hangul
  (539 / ~700 distinct codepoints used in dialog). Strings with
  several `[XXXX]` markers are correspondingly less readable.

## Refreshing

```bash
# After editing codepoint_map.json or pulling a new ROM
python3 tools/moneo/scan_rom_2024.py        # rebuild corpus
python3 tools/moneo/walk_scripts_v2.py      # rebuild map_text_index
python3 tools/moneo/build_mapsec_dialog.py  # regroup by mapsec
python3 tools/moneo/build_text_by_area.py   # regenerate this folder
```
